# Cart Abandonment Rescue

**Zion Cart Abandonment Rescue** — AI-timed recovery outreach and checkout-friction analysis that wins back lost carts.

> Part of the **Zion AI App Network** — see [ZION_APP_NETWORK.md](./ZION_APP_NETWORK.md) for the full mesh of interlinked apps.

Live app: https://ziontechgroup.com/cart-abandonment-rescue/

## ✨ Features
- **AI-timed outreach** — per-shopper optimal send time and channel (email, SMS, push, WhatsApp).
- **Incentive optimizer** — smallest discount (or none) that recovers each cart.
- **Checkout friction audit** — pinpoints the exact step and cause of drop-off.
- **Recovery sequences** — adaptive multi-touch flows that stop when the cart converts.
- **Revenue attribution** — recovered revenue dashboard with holdout-based truth.
